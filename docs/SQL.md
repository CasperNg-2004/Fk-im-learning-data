## SQL
- SQL = Structured Query Language
- Function: Access and manipulated the databases

## What it can do
- Execute queries against a database
- Retrieve data from a database
- Insert records in a database
- Update records in a database
- Delete records in a database
- Create new databases
- Create new tables in a database
- Create stored procedures in a database
- Create views in a database
- Set permissions on tables, procedures, and views

Query: Request/Action on a database
Stored Procedure: saved collection of SQL queries stored directly inside a database

## Using SQL in WEBSITE
To build a website that shows data from a database, you will need:
- An Relational Database Management System (RDBMS) database program (i.e. MS Access, SQL Server, MySQL)
- Use a server-side scripting language, like PHP or ASP
- Use SQL to get the data you want
- Use HTML/CSS to style the page

RDBMS - basic of SQL
-Data in RDBMS is stored in database objects called tables. 
Table: Collection of related data entries and consists of columns and rows

##Different of Functions and Stored Procedure
|  | SQL FUNCTION | Stored Procedure |
| ---  | --- | --- |
| Main Uses | Compute and return a value | Perform actions and workflows |
| Return Value? | Yes | No |
| Can Modify Data? | No | Yes |
| How to Run it | Inside a normal query (SELECT, WHERE) | Standalone command (CALL or EXEC) |

## Components of a DataBase
Database : The main digital filing cabinet (e.g., an online store's system)
Table    : Individual spreadsheet inside that cabinet (e.g., customers, orders, products)
Column   : Vertical category of data (Category such as name, email, price) 
Row(Record): Horizontal entry in the table
Primary Key: A unique number assigned to every rows
